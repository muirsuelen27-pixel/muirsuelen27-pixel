## Focus

I explore programming, Linux, networking, defensive cybersecurity, AI, hardware, and games. This profile collects public work and learning projects with an emphasis on clear documentation and responsible use.

## Featured work

### [Web__Scanner](https://github.com/muirsuelen27-pixel/Web__Scanner)

A public Python CLI project for authorized web reconnaissance and defensive auditing. Its documentation covers DNS, TLS, and security-header analysis, technology detection, optional network/content checks, and JSON reporting. It distinguishes observed signals from confirmed vulnerabilities and is intended only for systems you own or are explicitly authorized to assess.

### AEGIS

A private project under active development. Its source code and implementation details are intentionally not published.

## Principles
